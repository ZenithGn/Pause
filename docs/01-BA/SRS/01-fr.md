# SRS – Yêu cầu chức năng (Functional Requirements)

## FR-01: Xác thực & Quản lý tài khoản (Authentication & Account)

### FR-01.1: Đăng ký tài khoản

| Mục | Chi tiết |
|---|---|
| **ID** | FR-01.1 |
| **Mô tả** | Người dùng có thể đăng ký tài khoản mới bằng email/mật khẩu hoặc đăng nhập qua Google |
| **Actor** | Guest |
| **Tiền điều kiện** | Người dùng chưa có tài khoản |
| **Luồng chính** | 1. Guest chọn "Đăng ký" → 2. Nhập email, mật khẩu, tên hiển thị → 3. Xác nhận email → 4. Tài khoản được kích hoạt |
| **Luồng thay thế** | Đăng ký qua Google OAuth 2.0 |
| **Hậu điều kiện** | Tài khoản được tạo, user nhận 3 ngăn kéo mặc định (trống) |
| **Độ ưu tiên** | 🔴 Cao |

### FR-01.2: Đăng nhập

| Mục | Chi tiết |
|---|---|
| **ID** | FR-01.2 |
| **Mô tả** | Người dùng đăng nhập bằng email/mật khẩu hoặc Google |
| **Actor** | Guest |
| **Tiền điều kiện** | Tài khoản đã được đăng ký và kích hoạt |
| **Luồng chính** | 1. Guest nhập email + mật khẩu → 2. Hệ thống xác thực → 3. Trả về JWT token → 4. Chuyển đến màn hình chính |
| **Xử lý lỗi** | Sai mật khẩu → thông báo lỗi. Quá 5 lần → khóa tạm 15 phút |
| **Độ ưu tiên** | 🔴 Cao |

### FR-01.3: Đăng xuất

| Mục | Chi tiết |
|---|---|
| **ID** | FR-01.3 |
| **Mô tả** | Người dùng đăng xuất khỏi ứng dụng |
| **Actor** | User |
| **Hậu điều kiện** | Session/token bị thu hồi, chuyển về màn hình đăng nhập |
| **Độ ưu tiên** | 🔴 Cao |

### FR-01.4: Quên mật khẩu

| Mục | Chi tiết |
|---|---|
| **ID** | FR-01.4 |
| **Mô tả** | Người dùng có thể reset mật khẩu qua email |
| **Actor** | Guest |
| **Luồng chính** | 1. Nhập email → 2. Nhận link reset → 3. Đặt mật khẩu mới |
| **Độ ưu tiên** | 🟡 Trung bình |

### FR-01.5: Quản lý hồ sơ cá nhân

| Mục | Chi tiết |
|---|---|
| **ID** | FR-01.5 |
| **Mô tả** | Người dùng xem và chỉnh sửa thông tin cá nhân (tên, avatar, số điện thoại) |
| **Actor** | User |
| **Độ ưu tiên** | 🟡 Trung bình |

## FR-02: Ngăn kéo Kỷ niệm (Memory Drawers)

### FR-02.1: Xem danh sách ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.1 |
| **Mô tả** | Hiển thị tất cả ngăn kéo mà user sở hữu hoặc được chia sẻ |
| **Actor** | User |
| **Dữ liệu hiển thị** | Tên ngăn kéo, ảnh bìa, số lượng ảnh, dung lượng đã dùng, trạng thái (của tôi / được chia sẻ) |
| **Độ ưu tiên** | 🔴 Cao |

### FR-02.2: Tạo ngăn kéo mới

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.2 |
| **Mô tả** | User tạo ngăn kéo kỷ niệm mới |
| **Actor** | User |
| **Tiền điều kiện** | User chưa đạt giới hạn ngăn kéo (3 cho free, nhiều hơn cho member) |
| **Luồng chính** | 1. Chọn "Tạo ngăn kéo" → 2. Nhập tên, mô tả, chọn ảnh bìa (tuỳ chọn) → 3. Xác nhận → 4. Ngăn kéo trống được tạo |
| **Xử lý lỗi** | Đã đạt giới hạn → Hiển thị gợi ý nâng cấp hội viên hoặc mua lẻ |
| **Quy tắc** | Free user: tối đa 3 ngăn kéo. Mỗi ngăn kéo giới hạn 1 GB |
| **Độ ưu tiên** | 🔴 Cao |

### FR-02.3: Chỉnh sửa ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.3 |
| **Mô tả** | Chỉnh sửa tên, mô tả, ảnh bìa của ngăn kéo |
| **Actor** | User (chủ sở hữu hoặc người có quyền edit) |
| **Độ ưu tiên** | 🟡 Trung bình |

### FR-02.4: Xóa ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.4 |
| **Mô tả** | Xóa ngăn kéo và toàn bộ ảnh bên trong |
| **Actor** | User (chỉ chủ sở hữu) |
| **Luồng chính** | 1. Chọn xóa → 2. Xác nhận (dialog cảnh báo) → 3. Ngăn kéo bị xóa vĩnh viễn |
| **Quy tắc** | Không thể khôi phục sau khi xóa. Chỉ chủ sở hữu mới được xóa |
| **Độ ưu tiên** | 🟡 Trung bình |

### FR-02.5: Upload ảnh vào ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.5 |
| **Mô tả** | User upload ảnh từ thiết bị hoặc camera vào ngăn kéo |
| **Actor** | User (chủ sở hữu hoặc người có quyền edit) |
| **Luồng chính** | 1. Mở ngăn kéo → 2. Chọn "Thêm ảnh" → 3. Chọn ảnh từ gallery hoặc chụp trực tiếp → 4. Ảnh được upload & hiển thị trong ngăn kéo |
| **Quy tắc** | Kiểm tra dung lượng trước khi upload. Nén ảnh tự động nếu cần. Hỗ trợ upload nhiều ảnh cùng lúc (batch upload) |
| **Giới hạn** | Dung lượng tối đa mỗi ngăn kéo: 1 GB |
| **Độ ưu tiên** | 🔴 Cao |

### FR-02.6: Xem & quản lý ảnh trong ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.6 |
| **Mô tả** | Xem ảnh dạng grid/list, xem ảnh full-screen, xóa ảnh |
| **Actor** | User (chủ sở hữu hoặc người có quyền tương ứng) |
| **Chức năng** | Xem grid → tap để full-screen → pinch-to-zoom. Chọn nhiều ảnh → xóa batch. Xem thông tin ảnh (ngày upload, kích thước) |
| **Độ ưu tiên** | 🔴 Cao |

### FR-02.7: Chia sẻ ngăn kéo

| Mục | Chi tiết |
|---|---|
| **ID** | FR-02.7 |
| **Mô tả** | Chủ sở hữu chia sẻ ngăn kéo cho người dùng khác với quyền cụ thể |
| **Actor** | User (chủ sở hữu) |
| **Luồng chính** | 1. Mở settings ngăn kéo → 2. Chọn "Chia sẻ" → 3. Nhập email/username người nhận → 4. Chọn quyền (Xem / Chỉnh sửa) → 5. Gửi lời mời |
| **Quyền hạn** | **Xem (View)**: Chỉ xem ảnh, không upload/xóa. **Chỉnh sửa (Edit)**: Xem + upload ảnh + chỉnh sửa thông tin ngăn kéo |
| **Quy tắc** | Chủ sở hữu có thể thu hồi quyền bất cứ lúc nào. Người được chia sẻ không thể chia sẻ tiếp |
| **Độ ưu tiên** | 🔴 Cao |

## FR-03: In ảnh Photobooth (Photobooth Print-on-Demand)

### FR-03.1: Duyệt template photobooth

| Mục | Chi tiết |
|---|---|
| **ID** | FR-03.1 |
| **Mô tả** | Hiển thị danh sách template photobooth có sẵn (miễn phí + premium) |
| **Actor** | User |
| **Dữ liệu hiển thị** | Ảnh preview template, tên, tag (miễn phí/premium), số slot ảnh |
| **Lọc/Sắp xếp** | Theo category (couple, bạn bè, gia đình...), theo giá (free/premium) |
| **Độ ưu tiên** | 🔴 Cao |

### FR-03.2: Tạo photobooth từ template

| Mục | Chi tiết |
|---|---|
| **ID** | FR-03.2 |
| **Mô tả** | User chọn template, fill ảnh từ ngăn kéo vào các slot, xem preview |
| **Actor** | User |
| **Luồng chính** | 1. Chọn template → 2. Hệ thống hiển thị template với các slot ảnh trống → 3. User chọn ảnh từ ngăn kéo để fill vào từng slot → 4. Xem preview kết quả → 5. Xác nhận hoặc chỉnh sửa lại |
| **Quy tắc** | User **không** được chỉnh sửa layout/vị trí chữ của template. User chỉ được fill ảnh vào các slot đã định sẵn. Ảnh được tự động crop/fit vào slot |
| **Độ ưu tiên** | 🔴 Cao |

### FR-03.3: Đặt in photobooth

| Mục | Chi tiết |
|---|---|
| **ID** | FR-03.3 |
| **Mô tả** | User đặt in photobooth đã tạo |
| **Actor** | User |
| **Luồng chính** | 1. Xem preview → 2. Chọn số lượng bản in → 3. Nhập địa chỉ giao hàng → 4. Chọn phương thức thanh toán → 5. Xác nhận & thanh toán → 6. Đơn hàng được tạo |
| **Dữ liệu đơn hàng** | Mã đơn, template, ảnh preview, số lượng, giá, địa chỉ, trạng thái |
| **Độ ưu tiên** | 🔴 Cao |

### FR-03.4: Theo dõi đơn hàng

| Mục | Chi tiết |
|---|---|
| **ID** | FR-03.4 |
| **Mô tả** | User xem danh sách và trạng thái đơn hàng đã đặt |
| **Actor** | User |
| **Trạng thái đơn** | Chờ xác nhận → Đang xử lý → Đang in → Đang giao → Hoàn thành / Đã hủy |
| **Độ ưu tiên** | 🟡 Trung bình |
